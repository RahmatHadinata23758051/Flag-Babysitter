# Systems worker template

Use this template for blockchain, cloud, mobile, hardware, ICS/OT, game, satellite, or other system-specific challenges. Identify the supplied artifact, simulator, disposable instance, chain, device, or endpoint before interaction. Prefer offline analysis, read-only inspection, local simulation, and event-provided disposable resources.

Confirm boundaries before active actions: do not touch public cloud tenants, wallets/funds, app-store services, real equipment, operational RF bands, adjacent networks, or real control systems. A live action is allowed only when the event explicitly supplies the instance, rules, and required operation.

Model the relevant state transition or data transformation, then perform the smallest permitted validation. Preserve tool versions, state assumptions, transaction or request identifiers when non-sensitive, and solver artifacts. Report why the target was in scope and what proves the result.

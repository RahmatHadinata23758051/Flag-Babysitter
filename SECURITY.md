# Security policy

Flag Babysitter is intended for authorized CTFs, training labs, and supplied challenge bundles. It must not direct work toward unrelated infrastructure, real accounts, or operational systems.

## Reporting a security or safety concern

Use a GitHub private security advisory for this repository when available. If private reporting is unavailable, contact the repository owner through their GitHub profile and include only the minimum reproducible information.

Do not include credentials, active challenge flags, private competition artifacts, or details that would enable access to systems outside an authorized scope.

## Out of scope

Requests to add account brute force, rate-limit evasion, persistence, broad scanning, stealth, or activity against real-world targets are out of scope for this project.

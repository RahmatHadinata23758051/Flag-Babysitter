# OSINT and misc worker template

Classify the task before choosing tools. It may be an encoding, language puzzle, jail, audio/image problem, protocol oddity, constraint system, public-source research task, or a hybrid. Build one small testable hypothesis and retain intermediate transformations.

For OSINT, use only event-permitted public sources and supplied clues. Record URLs, timestamps, and the reasoning that connects evidence to the answer. Do not contact, impersonate, harass, expose private individuals, or use leaked credentials. For jails and remote puzzles, use only the named challenge service with bounded requests.

Automate repeatable transformations when useful, but preserve enough intermediate output to audit the result. Distinguish sourced facts, inference, and guesses in the report.

# Compatibility and third-party material

Flag Babysitter is a self-contained source tree for three repository-owned Codex skills. Its bundled worker templates provide the portable fallback path; a user does not need an external skill pack for the documented workflow.

## When another skill is already installed

An installed specialist skill may be selected as focused supplemental material when it is relevant to the challenge and compatible with the higher-priority event rules, task card, and safety boundaries. It does not become a dependency of Flag Babysitter, and it cannot expand the worker's authorization, endpoint allowlist, credential access, or submission authority.

Record the selected supplement and its purpose in the worker task card. If it is unavailable, use the relevant bundled worker template instead and report any remaining knowledge gap.

## What this repository does not distribute

This repository does not copy, repackage, or claim ownership of third-party skills, prompts, references, logos, or assets. Names used in the routing guide are examples of optional integrations, not bundled content or endorsements.

Before proposing an integration reference, confirm the upstream source and license. Link to it rather than copying its text unless its license explicitly permits the intended reuse and the contribution carries the required attribution. If that cannot be established, do not include the material.

## Personal or event-specific templates

A user-supplied or event-supplied category template is primary technical guidance for that event when it is present. It remains outside this repository unless its owner separately contributes it under a compatible license. Flag Babysitter's task contract and authorization boundaries still apply.
